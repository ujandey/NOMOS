# Three-minute demo

| Time | Action |
| --- | --- |
| 0:00 | Choose **Try the straightedge**. Start at 80% precision and 90% recall. Drag one marker and point to the moving crossing. |
| 0:25 | Open **Why the line computes**. Point to the measured middle coordinate and inverse readout. Toggle the numerical check to show independent agreement. |
| 0:55 | Choose **Use model inputs** and sweep Balanced thresholds. Read the precision, recall and F1 changes. Open evidence to inspect confusion counts, intervals and synthetic benchmark provenance. |
| 1:20 | Open **Inference cost**. At one million requests and $0.003 per request, the middle scale reads $3,000. Drag the volume handle or type a new forecast. |
| 1:50 | Press **Tighten to 50 ms**. The selected point stays pinned and fails latency. The map reports zero feasible points and shows evaluated trade-offs. |
| 2:10 | Restore defaults. Open **Mission Compiler**, select **Use example**, preview the diff and apply it. |
| 2:35 | Restore defaults and select the ranked Balanced 0.50 operating point. Export both formats and inspect the alignment coordinates, mission and dataset hash. |
| 2:55 | Close with the mechanism. The calibrated scales let the straightedge compute two equations. A four-objective solver checks the deployment constraints. |
