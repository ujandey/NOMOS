# Decisions

Ship a local, static-first Vite/React/TypeScript app in this workspace. Python generates versioned evidence. Core calculations, filtering, and downloads run in the browser. The optional model-provider adapter uses server-only credentials.

The build sequence places both geometric instruments and their independent tests before the ML and mission integrations.

Constraint limits are inclusive with a 1e-9 tolerance in each metric's native unit. Pareto dominance compares full-precision values so near-equal trade-offs cannot create dominance cycles. Ranking resolves exact ties by cost, then ID. Closest infeasible alternatives sort by number of failed gates and then a sum of violations normalized by 100 ms, 5 USD per 1,000 requests, and one unit of each classification ratio.

The free instrument permits zero as a boundary. Positive F1 inputs and unit prices accept values down to 1e-12 in native units. Request volumes are whole numbers up to 1 trillion. The workbench independently verifies each finite geometric reading. Calibration details and verification errors are available on demand and included in exports for the selected ML record. The chart holds its scale during a drag and adapts its bounds for inputs outside the initial plotted ranges.

Intervals use the Wilson score method. The provider adapter uses the OpenAI-compatible Chat Completions contract with a local deterministic grammar for offline use.
