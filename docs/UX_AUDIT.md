# NOMOS V2 UX audit

## Baseline

I ran the existing production server and used Chromium to take [desktop](ux-screenshots/before-desktop.png), [tablet](ux-screenshots/before-tablet.png), and [phone](ux-screenshots/before-mobile.png) screenshots at 1440 × 900, 820 × 960, and 390 × 844. The baseline includes model and threshold changes, an evidence comparison, the 50 ms preset and reset, offline mission preview and apply, free F1 and cost, extreme and invalid volume, export inspection, and browser history. Repository review covered the V2 requirements, README, specs, fixture generator and manifests, geometry and envelope engines, frontend, server routes, and existing tests.

## Journey observations

- **First visit.** The headline uses “analog brain” and “operating points” before defining the job. The chart starts in linked mode and looks draggable. The first model control begins at y=1,061 on desktop and y=946 on the phone. A new visitor can see the result without finding the controls that produced it or knowing what F1 measures.
- **ML engineer.** Dataset counts are visible, while dataset ID and lineage require opening candidate evidence. Selecting a model and changing thresholds works. The chart and candidate metrics change above and below the fold. Threshold changes offer no proportional explanation of the trade-off. The evidence comparison and default mission reset work. The selected point stays pinned when the mission tightens.
- **Judge.** The calculation is genuine and the evidence in “Why the line computes” is inspectable. Dragging requires discovering Free instrument, and historical context is missing from the interaction. The 50 ms preset correctly drops the feasible count to zero. The reasons and nearest evaluated alternatives sit below the operating envelope.
- **Adversarial user.** Fractional request volume was rejected. Rapidly editing a prompt while an offline response was pending displayed an error for the former prompt. Exporting after changing free volume captured the linked candidate and one-million-request volume with no contextual indication. Browser Back retained the selected threshold after an in-page navigation. The mathematical kernels and fixture generator remain deterministic.

## Findings and acceptance

| ID | Class / severity | Reproduction and impact | Proposed correction | Verification |
| --- | --- | --- | --- | --- |
| M1 | Mathematical / high | Three comparable points with precision, recall and inverse latency offsets of (2,1,0), (0,2,1) and (1,0,2) in units of 0.75e−9 produce a dominance cycle. All three points disappear from the Pareto frontier. | Use exact weak and strict comparisons for dominance. Keep tolerance for mission boundaries. | Regression for the cycle and property checks over independent objective directions. |
| M2 | Mathematical display / high | Open Free instrument → Inference cost → set volume to 999999999999. A positive $0.001 tick on the center scale is printed as $0 by compact formatting. | Use explicit scientific or currency formatting for very small positive ticks. | Assert positive ticks never print as zero and compare cost against multiplication over the supported ranges. |
| F1 | Functional / high | On desktop, press 14 pixels below the precision handle center and move 3 pixels horizontally. Precision jumps from 0.80 to about 0.767. Mouse or touch contact inside the hit region changes the value even when the finger moves parallel to the axis labels. | Preserve the initial grab offset in model coordinates and snapshot the calibration through release. | Test off-center grabs, zoom, resize, capture, and touch against the expected coordinates. |
| F2 | Functional / high | Add a delay to the offline response. Preview “Bad instruction,” then replace the text with “latency under 50 ms.” The discarded instruction’s error appears under the replacement. | Scope errors and drafts to the submitted text and mission snapshot. | Simulate a delayed offline request and then preview the current text. |
| F3 | Functional / medium | Clear the 100 ms field and type “1000.” The live solver applies 1, 10, 100 and 1,000 ms as the user types. Candidate status and count can flicker through an unrelated failure. | Commit numeric edits on Enter or leaving the field. Escape cancels. | Check status before commit, after commit and after invalid input. |
| F4 | Functional / medium | The initial manifest uses a throwing parse during module import. A malformed bundle never reaches React, so the page has no useful error state. | Validate without throwing at module load and render an explicit recovery state. | Unit and browser exercises for malformed, empty, and missing metric variants. |
| A1 | Accessibility / high | Open candidate evidence and press Escape. Focus returned to the body in Chromium. The map adds 27 stops to sequential Tab navigation. | Return focus to the opener. Group map navigation with a roving focus point and offer the data table. | Keyboard tests cover focus restoration, selected map navigation, and accessible names. |
| A2 | Accessibility / high | At 390px the chart is 338 × 125px. Scale labels render around 8px and SVG markers’ 44-unit hit areas render close to 20px. Status in the decision map also depends on fill color for points with the same shape. | Keep chart height and readable labels at narrow widths. Give handles larger targets and use a distinct feasible mark. | Inspect phone and tablet renderings and test touch, keyboard, zoom, and automated accessibility. |
| U1 | UX / high | The first view gives the largest space to broad positioning. Two different toggles and a collapsed equation precede the primary setup. The model picker and threshold are off the first screen at each tested size. | Lead with the job and place the evaluated inputs above the chart. Offer one visible action to start dragging. | Verify the first view includes input selection, the chart and instructions at the tested sizes. |
| U2 | UX / high | The candidate’s failed limits, overall feasible count, and available alternatives are in three separate regions. Switching thresholds changes numbers without summarizing what changed. | Attach selected-vs-limit rows and immediate alternatives to the instrument. Show precision, recall and F1 deltas on selection or completed adjustment. | Check a threshold move and the 50 ms preset without navigating away. |
| V1 | Visual / medium | Large rounded cards carry similar icon headings and badges. The introductory area consumes 262px before the product begins at 1440px. At intermediate widths the sidebar and instrument stack without prioritizing input or output. | Use a single instrument frame with calibrated chart paper, a thin operating-point strip and a connected limits register. Use the same structure at narrow widths. | Compare same-size screenshots and inspect clipping and contrast. |
| C1 | Design cliché / medium | Generic hero, ornamental icons, repeated segmented pills and an open AI input are the most recognizable motifs in the first screenshot. These visual cues compete with the straightedge. | Use etched scale labels and clearly machined markers for the distinctive details. Put text parsing behind demand. | Measure chart position and inspect all three viewports. |
| P1 | Performance / medium | Source inspection shows every pointer move replaces state and recreates identical scale ticks and SVG axis elements. Updating numeric mission prefixes also reruns both Pareto calculations. The entry bundle eagerly includes YAML serialization. | Keep the plate stable while the line moves, coalesce pointer updates to animation frames, commit limit edits, and load YAML serialization only when exporting. | Check the production bundle split and exercise rapid pointer and input changes. |
| X1 | Misleading functionality / high | In Free instrument, set volume to 999999999999 and export. The JSON has 1,000,000 requests and the current model’s unit cost. The free readout and scope lack an explanation. | Mark free input as exploratory, state the decision scope next to export, show the exact linked volume and current metrics, and clear old feedback when the state changes. | Compare both downloaded files to linked state after changing free and linked values, including an injected download-preparation failure. |
| X2 | Missing discoverability / medium | The data source is displayed as a static badge. ID, seed and profile methodology are buried inside candidate evidence. Historic alignment details are available only as equations. | Add a source inspector and a short explanation of the historical method above the calibration proof. | Open source and evidence independently and confirm dataset identity and numerical agreement. |

The original F1 and cost coordinate transforms agreed with their independent references in the existing tests. Findings M1 and M2 concern dominance and axis labeling respectively. No production benchmark data is present.
